# Akhyana Website

This is the official public-facing website for the Akhyana learning platform, built with Next.js, Tailwind CSS, and TypeScript.

## Vercel Deployment

This website is configured to deploy directly to Vercel:

1. Import this repository into Vercel.
2. In the **Root Directory** setting, type `web`.
3. The framework preset will automatically detect **Next.js**.
4. Click **Deploy**.

## Local Development

To run the website locally:

```bash
cd web
npm install
npm run dev
```
