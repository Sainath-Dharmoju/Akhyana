# Akhyana

Akhyana is a game-based learning platform for experiencing and understanding India's history, culture, and heritage.

## Development

```bash
npm start
```

Useful checks:

```bash
npx tsc --noEmit
npx expo export --platform android
```

The app uses Expo, React Native, TypeScript, and Expo Router. The current prototype is centered on the Indus Valley Civilization.
